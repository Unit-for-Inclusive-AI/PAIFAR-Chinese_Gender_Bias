# PAIFAR v2.4 Public Release — Revision 1

This package contains the two core benchmark CSV files, bilingual taxonomies, data dictionary, value mapping, README, and Data Card.

It excludes master editing workbooks, blind annotation files, private gold manifests, inter-annotator disagreement files, and ACL drafting assets.

Benchmark size: 717 Golden Negative + 871 Golden Positive = 1,588 instances.
